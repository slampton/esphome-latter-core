Pocket Assistant (1.75" Round AMOLED)

Target: Waveshare ESP32-S3-Touch-AMOLED-1.75C • 466×466 Circular QSPI AMOLED

Onboarding Steps

  1. Click Connect & Install above and select your board's USB serial port in Chrome or Edge.
  2. Once flashing completes, configure Wi-Fi directly in the browser dialog (or connect via Improv BLE).
  3. Install Latter (ha-latter) via HACS in Home Assistant and accept the auto-discovered device.
  4. Prefer compiling in ESPHome Device Builder? Browse the turnkey YAML configs in esphome-latter-core/devices/.
