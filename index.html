Won't boot after flashing? Switch ESP32-P4 silicon batch

Early 86-Panel units use revision v1.x (pre-selected); newer Waveshare batches ship with v3.x. If your board logs a chip revision mismatch at boot, select the other batch and flash again.

Onboarding Steps

  1. Click Connect & Install above and select your board's USB serial port in Chrome or Edge.
  2. Once flashing completes, configure Wi-Fi directly in the browser dialog (Improv Serial over the same USB cable).
  3. Add the discovered ESPHome device in Home Assistant (leave Allow the device to perform Home Assistant actions off), install Latter (ha-latter) via HACS, and accept Discovered: Latter.
  4. Prefer compiling in ESPHome Device Builder? Browse the turnkey YAML configs in esphome-latter-core/devices/.
